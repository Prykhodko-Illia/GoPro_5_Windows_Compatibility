# GoPro Webcam: GoPro HERO5 як вебкамера в Discord (Windows)

Програма бере картинку з GoPro HERO5 по Wi‑Fi і показує її як звичайну вебкамеру
«OBS Virtual Camera». Її можна вибрати в Discord, Zoom, Teams, Telegram, Google Meet.
Нічого купувати не треба.

## Швидкий старт

1. Завантаж **GoProWebcam.exe** зі сторінки **Releases** цього репозиторію.
2. Запусти його. Якщо Windows напише «Невідомий видавець», натисни «Докладніше» → «Все одно запустити».
3. Пройди кроки у вікні зверху вниз. Програма сама перевіряє кожен крок і ставить ✓,
   а біля кроку з ✗ є кнопка з поясненням, що робити.

| Крок | Що потрібно |
|---|---|
| 1. Драйвер вебкамери | Безкоштовна [OBS Studio](https://obsproject.com/download). Встанови, відкрий один раз, натисни **Start Virtual Camera** → **Stop**, закрий. Під час роботи програми OBS не потрібна. |
| 2. GoPro на зв'язку | На камері увімкни Wi‑Fi (**Connect → GoPro App**) і підключи комп'ютер до її Wi‑Fi мережі. Назву й пароль показує камера. |
| 3. Інтернет для Discord | Wi‑Fi зайнятий камерою, тому інтернет потрібен через **кабель** або **телефон по USB у режимі модема**. |
| 4. Відео з камери | Натисни **▶ Старт**. Якщо Windows спитає про брандмауер, дозволь для приватних і публічних мереж. |
| 5. Discord | **Налаштування → Голос і відео → Камера → OBS Virtual Camera**. Якщо камери немає в списку, перезапусти Discord. |

Кольорові смуги замість картинки означають, що програма працює, але відео з камери поки не приходить.

## Чесно про якість

Це потік попереднього перегляду, той самий, що в застосунку GoPro Quik: приблизно 480p, затримка близько 0,5–1 с,
іноді бувають артефакти через Wi‑Fi. Для дзвінків вистачає. Повну якість дає тільки HDMI → карта захоплення
(лише HERO5 Black, у Session немає HDMI).

## Режим для OBS

**⚙ Налаштування → «Тільки запустити потік»**, потім «Старт». В OBS: **Sources → Media Source**,
зніми «Local File», Input `udp://@:8554`, Input Format `mpegts`, потім **Start Virtual Camera**.

## Для розробника

```
gopro_webcam.py   точка входу (+ --self-test для перевірки зібраного exe)
gopro.py          HTTP API камери: старт потоку, інформація про модель
bridge.py         keep-alive, прийом UDP MPEG-TS, декодування, вихід у віртуальну камеру
checks.py         перевірки для майстра: віртуальна камера, інтернет
ui.py             вікно-майстер (tkinter)
tests/            імітація GoPro (HTTP + H.264 по UDP) і димовий тест вікна
```

- **CI (GitHub Actions):** на кожен push у `main` проганяє тести на Windows, збирає exe і запускає
  `GoProWebcam.exe --self-test`. Exe лежить в Actions → запуск → Artifacts.
  Push тегу `v*` (наприклад `v1.0.0`) публікує exe у **Releases**, звідки його може завантажити будь-хто.
- **Локально на Windows:** Python 3.11 (з галочкою «Add to PATH») → `build.bat` → `dist\GoProWebcam.exe`.
- **Тести:** `pip install -r requirements.txt`, потім `python tests/test_bridge.py` і `python tests/test_ui.py`.
